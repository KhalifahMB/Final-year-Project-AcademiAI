# Requirements Specification

## Core entities

Tenant, Faculty, Department, Programme, Academic Session, Semester, User, Student Profile, Lecturer Profile, Course, Curriculum Course, Course Offering, Lecturer Assignment, Course Enrollment, Resource, Resource Version, Resource Chunk, Concept, Resource Concept, Concept Edge, Chat Session, Chat Message, Chat Message Source, Quiz, Quiz Question, Quiz Attempt, Note, Bookmark, Progress Record, Resource Permission, Audit Log.

## Requirement traceability

Every implemented requirement should map to:
- one or more API operations
- one or more UI workflows
- one or more database entities
- authorization rules
- tests

## Priority

P0: authentication, tenant isolation, academic structure, course enrollment, resources, RAG authorization.

P1: quizzes, notes, bookmarks, progress, advanced concept graph features.

P2: future adaptive sequencing and advanced analytics.
